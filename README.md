# Train18-Vande-Bharat-Express-Model-Blender
This is one of my biggest project I have ever done. This one was made on Blender as I was only good in Blender before beginning with CATIA.

I made this blender model when I was in 11th and 12th. Took me 4 to 5 months to get it where it is currently. I was initially a Blender user before I got along with CATIA.

This model was actually created because I wanted to make it a pay-ware game asset/addon/plugin in Trainz Simulator by N3V Games PTY LTD. But the plan went down as I had to focus on my 12th class exams, CET, JEE and all the other competitive exams I had appeared to. 

There are several free-ware cads in it from websites like Sketchfab, supporting this blender model. Though I tried my level best in creating it myself as much as possible. And I can proudly say that 85-90% factors in it are created by me.

I hope, you all like this model.
